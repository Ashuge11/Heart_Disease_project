# ❤️ Heart Disease Prediction Using Machine Learning

## 📌 About the Project
Heart Disease Prediction is a Machine Learning project that aims to predict the likelihood of heart disease using clinical features such as age, sex, chest pain type, blood pressure, cholesterol, maximum heart rate, and other health-related parameters.

The project focuses on data preprocessing, Exploratory Data Analysis (EDA), feature engineering, model training, and evaluation using Python and Scikit-learn.

## 🎯 Objectives
- Analyze heart disease dataset using EDA.
- Handle missing values and prepare data for training.
- Identify numerical and categorical features.
- Train and evaluate classification models.
- Generate predictions based on input features.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
